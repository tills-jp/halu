## N05 分割処理（分割数3）による全件処理の整合性

```sql
SELECT バッチ分割管理ＩＤ, 開始日時, 終了日時 FROM バッチ分割管理 WHERE バッチ管理ＩＤ = 21 ORDER BY バッチ分割管理ＩＤ;
```

- 3行取得、いずれも開始日時・終了日時ともIS NOT NULL（開始 09:42:46／09:42:49／09:42:53）
- 6キーが3分割に均等配分（2キーずつ）され、3分割の処理結果を合算するとN01と同じ全6明細一致（欠落・重複なし）
