## 0. 種別決定の経緯

テーママスタ（テーマコード・テーマ名称・使用中フラグの3項目）を一覧表示し、「使用中」の切り替えと削除のみをテーブル上で行う画面のため、`screen_types.md`の`list-mainte`に該当する。ただし本画面はテーマコード・テーマ名称の新規入力ができない（後述）等、一般的なlist-mainteパターンと異なる制約を持つ。

---

## 1. 要件

| 要件ID | 区分 | 要件 | 背景・理由 |
|--------|------|------|-----------|
| REQ-001 | 表示 | 登録済みの全テーマを一覧表示する（ページングなし） | テーマ件数は少数であるため全件表示とする |
| REQ-002 | 選択 | 一覧の「使用」列（ラジオボタン）をクリックして、システム全体で使用するテーマを1つ選択できる（排他選択） | 全ユーザ共通の既定テーマ切り替え |
| REQ-003 | 削除 | 「削除」列のチェックボックスにチェックを付けた行は、「実行」ボタン押下時にテーマ一覧から除外される | 不要テーマの整理 |
| REQ-004 | 実行 | 「実行」ボタン（F1）押下で、現在の一覧状態（使用選択・削除チェック除く行）をテーママスタへ一括反映する | 一覧編集の確定操作 |

## 4. 操作

| 操作 | キー | 動作 | 遷移先 |
|------|------|------|--------|
| 使用（行クリック） | - | クリックした行の「使用」を"1"に設定し、他の全行を空欄にする（排他選択）。あわせて選択したテーマのCSSを画面にプレビュー適用する | - |
| 実行 | F1 | 削除チェックの無い行のみを対象に、テーママスタを全件洗い替え（後述）する | - |
| 戻る | ESC | メニュー画面へ戻る | StartMenu / AdminMenu |

## 5. 特記事項

- **全件洗い替え（DELETE ALL→INSERT）方式**: 本画面の「実行」は、他画面（例:`CustomerListMainte`）のようなキー単位のUPDATE/INSERT振り分けではなく、`ThemeListMainte_execute_sql.json`の`delete`エントリで**テーマ全件を無条件でDELETEした後**、`insert`エントリで画面上の明細行（削除チェックの無い行のみ、`setDatasetToJsonRecordsNoDeleteLine`によりクライアント側で除外済み）を全件INSERTし直す方式である。テーマコード・テーマ名称は`disabled`で編集不可のため、この方式で実質的に変更されるのは「使用中フラグ」と「削除による行の除外」のみである。
- **監査列の記録（C-052・Issue #34）**: `insert`エントリは`登録日時`・`更新日時`（`CURRENT_TIMESTAMP`）に加え、`登録ユーザ`・`更新ユーザ`に`login.ユーザＩＤ`（ログイン中ユーザのＩＤ。common.md 3章の既定）を記録する。全件洗い替えのため、実行のたびに全行の登録ユーザ／更新ユーザ・登録日時／更新日時が実行者・実行時刻で上書きされる（2026-09-15より前はloginレコードを送信しておらず登録ユーザ／更新ユーザが空だった）。
- `delete`エントリは`freesql: "DELETE FROM テーマ"`（`crud: {"テーマ": "D"}`宣言あり）。WHERE句が無い全件削除であり、開発標準の禁止事項（テーブル名の変数化・freesql全体の組み立てをPython側で行うこと等）には抵触しないが、**削除→再挿入の間に他ユーザの同時実行があった場合の整合性（同時書き込み時の一時的なテーマ消失）は考慮されていない**。件数が少なく管理者のみが操作する想定のためリスクは小さいと考えられるが、要件定義書に明記された設計判断ではない。
- 「使用」列のラジオボタンは`name="使用"`をHTMLネイティブの排他グループとして維持している（`halu-ds-field`属性と併記。変更管理台帳C-006 例外(1)参照。datasetとの連携自体は`halu-ds`属性が優先で解決される）。
- テーマコード・テーマ名称に新規入力欄・行追加ボタンが無いため、本画面だけでは新しいテーマを追加できない（テーマの新規追加は本画面の対象外、既存テーマの使用中切替と削除のみが可能）。
- **登録テーマは現在`halu-custom_default`／`halu-custom_dark`／`halu-custom_navy`の3件**（2026-08-01 依頼者決定によりdefault以外の11テーマファイルとテーママスタ9件を削除して1テーマへ縮小したが（変更管理台帳C-025）、その後2026-08-30〜31にD-034（テーマ追加）・C-056（ファイル名改名とDB移行）によりdark／navyの2テーマが追加され、現在は3件）。したがって本画面の一覧は現在3行で、「使用」ラジオは3テーマの中から選択できる（既定テーマはdefaultのまま）。2章の画面モックの`dark`行は現行の実データである。**前項のとおり本画面からはテーマを追加できないため、さらにテーマを増やす場合は`Html/css/halu-custom_{名前}.css`の追加とテーママスタへのINSERTが別途必要**。

### 項目語彙（common.mdへ統合済み）

- 使用（使用中フラグ）はcommon.md 2.2の「使用中フラグ」行に統合済み（`テーマ.使用中フラグ` / number / - / ThemeListMainte, ThemePersonalListMainte（後者は算出値） / ラジオボタンによる排他選択値（"1"/空欄））
