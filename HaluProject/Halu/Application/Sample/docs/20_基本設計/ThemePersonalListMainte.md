## 0. 種別決定の経緯

登録済みの全テーマを一覧表示し、ログイン中ユーザ個人の使用テーマを選択・保存する画面のため、`screen_types.md`の`list-mainte`に該当する。`ThemeListMainte`（システム全体の既定テーマ設定）と画面構成は酷似するが、更新対象が「ログイン中ユーザ自身の`ユーザ.テーマコード`」である点が異なる（テーママスタ自体は更新しない・削除機能も持たない）。

---

## 1. 要件

| 要件ID | 区分 | 要件 | 背景・理由 |
|--------|------|------|-----------|
| REQ-001 | 表示 | 登録済みの全テーマを一覧表示し、ログイン中ユーザが現在選択しているテーマの「使用」列にマークを付けて表示する | 個人が現在どのテーマを使用中か分かるようにするため |
| REQ-002 | 選択 | 一覧の「使用」列（ラジオボタン）をクリックして、自分が使用するテーマを1つ選択できる（排他選択） | ユーザごとの見た目のカスタマイズ |
| REQ-003 | 実行 | 「実行」ボタン（F1）押下で、選択したテーマコードをログイン中ユーザの`ユーザ.テーマコード`へ保存する | 個人設定の確定操作 |

## 4. 操作

| 操作 | キー | 動作 | 遷移先 |
|------|------|------|--------|
| 使用（行クリック） | - | クリックした行の「使用」を"1"に設定し、他の全行を空欄にする（排他選択）。選択したテーマコードを`header.選択テーマコード`にも設定し、あわせて選択テーマのCSSを画面にプレビュー適用する | - |
| 実行 | F1 | `header.選択テーマコード`の値をログイン中ユーザの`ユーザ.テーマコード`へUPDATEする | - |
| 戻る | ESC | メニュー画面へ戻る | StartMenu / AdminMenu |

## 5. 特記事項

- `ThemeListMainte`（システム用テーマ設定）と異なり、本画面には**削除列・行追加が無い**。テーママスタ自体（`テーマ`テーブル）への追加・削除は行わず、あくまで「ログイン中ユーザがどのテーマを使うか」（`ユーザ.テーマコード`）のみを更新する。
- 「使用」列の判定はDBの実カラムではなく、照会時に`テーマ`と`ユーザ`（ログインユーザのみ）を`LEFT OUTER JOIN`した結果から都度算出している。したがって一覧表示のたびに現在のユーザ設定を反映するが、DB上に「テーマごとの使用中フラグ」を個人単位で永続化する専用カラム・専用テーブルは存在しない（`ユーザ.テーマコード`1カラムで表現）。
- 実行時のSQLは`update`（`ユーザ`テーブルのテーマコード列を更新）と、更新後の再照会（`detail`）の2件のみで、`ThemeListMainte`のような全件洗い替え（DELETE ALL→INSERT）は行わない。
- **監査列の記録（C-052・Issue #34）**: `update`エントリは`テーマコード`と`更新日時`（`CURRENT_TIMESTAMP`）に加え、`更新ユーザ`に`login.ユーザＩＤ`（common.md 3章の既定）を記録する（2026-09-15より前はloginをWHERE条件にだけ使い、更新ユーザは空のままだった）。
- 「使用」列のラジオボタンは`ThemeListMainte`と同様に`name="使用"`をHTMLネイティブの排他グループとして維持している（変更管理台帳C-006 例外(1)参照）。
- **登録テーマは現在`halu-custom_default`／`halu-custom_dark`／`halu-custom_navy`の3件**（2026-08-01 依頼者決定によりdefault以外の11テーマファイルとテーママスタ9件を削除して1テーマへ縮小したが（変更管理台帳C-025）、その後2026-08-30〜31にD-034（テーマ追加）・C-056（ファイル名改名とDB移行）によりdark／navyの2テーマが追加され、現在は3件）。したがって本画面の一覧も現在3行で、ユーザは3テーマの中から自分の使用テーマを選択できる（未選択時の既定は`ユーザ.テーマコード`のdefault）（本画面はテーマの追加・削除自体を行わないため、テーマを増やす場合は`ThemeListMainte`と同様に`Html/css/halu-custom_{名前}.css`の追加とテーママスタへのINSERTが別途必要）。2章の画面モックの`dark`行は現行の実データである。

### 項目語彙（common.mdへ統合済み）

- 選択テーマコード はcommon.md 2.2の「テーマコード」行の備考に統合済み（`ユーザ.テーマコード`（値の書き込み先） / text / - / ThemePersonalListMainte / 画面非表示の内部項目。DB上は既存の「テーマコード」と同一カラムのため、項目名としては「テーマコード」のUPDATE用エイリアスに相当する）
- 使用（個人用・算出値）はcommon.md 2.2の「使用中フラグ」行の備考に統合済み（JOIN結果から算出、DB実カラムなし / text / 1 / ThemePersonalListMainte / `ThemeListMainte`の「使用」（`テーマ.使用中フラグ`実カラム）とは出所が異なる同名項目）
